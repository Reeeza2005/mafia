# سند معماری و نقشه راه سیستم نقش‌های مافیا

این سند منبع حقیقت (Single Source of Truth) برای مدیریت قوانین، کارت‌ها و جریان فاز شب است.

## اصول اساسی:
1. رابط کاربری خام (Dumb UI): عدم قرارگیری منطق نقش‌ها در کامپوننت‌های فرانت‌اِند.
2. موتور شب خالص (Pure Night Engine): تابع مستقل resolveNight بدون وابستگی به React یا Socket.
3. کارت‌های داده‌محور (Role Registry): تعریف نقش‌ها به صورت ماژولار و مستقل.
